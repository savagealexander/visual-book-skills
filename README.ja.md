# Visual Book Skills · 図文知行

原文・図表・事例を出典と結び付け、再利用可能な Agent Skills に整理するプロジェクトです。

このフォークの最新の利用方法と制約については、[中文 README](./README.md) または [English README](./README.en.md) を参照してください。

図のレンダリングと実際の視覚的理解は別の工程です。画像を開き、本文との対応を確認してから、検証済みの証拠として記録します。

本プロジェクトは [kangarooking/cangjie-skill](https://github.com/kangarooking/cangjie-skill) を基に、図文読解と画像リソース対応を追加しています。[MIT License](./LICENSE) を保持しています。
